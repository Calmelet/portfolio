# Portfolio de Jules — BTS SIO SISR

Préparé à partir du modèle de la classe : https://github.com/AbidHamza/modele-portfolio-bts-sio

## Mettre en ligne

1. Créer ou ouvrir son compte GitHub.
2. Sur le modèle du professeur, cliquer sur « Use this template », puis « Create a new repository ».
3. Nommer le dépôt `portfolio` et sélectionner « Public ».
4. Extraire cette archive sur son ordinateur. Dans le dépôt, cliquer sur « Add file » > « Upload files ». Déposer le CONTENU du dossier portfolio, en conservant les sous-dossiers, puis « Commit changes ».
5. Compléter `_config.yml` avec son nom complet et une adresse de contact professionnelle destinée à être publique. Aucune adresse fictive n'a été ajoutée.
6. Dans « Settings » > « Pages », choisir « Deploy from a branch », branche `main`, dossier `/ (root)`, puis « Save ».
7. Attendre la réussite de « pages build and deployment » dans « Actions », puis ouvrir l'adresse fournie dans « Settings » > « Pages ».
8. Vérifier l'accueil et le projet. Faire les contrôles W3C et Lighthouse demandés dans le TP, puis ajouter les vraies captures dans `images` et les liens dans la fiche du projet.
9. Actualiser la description du projet et les compétences une fois les étapes réellement réalisées. Ne pas annoncer un score ou une publication avant de les avoir vérifiés.

Si le dépôt porte un autre nom, adapter `baseurl` dans `_config.yml`.

## Ajouter un projet

Copier `_projets/_A-COPIER.md` vers un nouveau fichier `.md` dans `_projets`, puis renseigner les cinq parties et justifier les compétences. Ajouter les captures dans `images`, avec un texte alternatif descriptif. Après le commit, vérifier la carte, le compteur et le tableau sur le site.
